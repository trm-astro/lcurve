class lcurve.BinaryModel#

BinaryModel is a class to contain the model and grids for a close binary system.

An instance of BinaryModel can be initialised either from an lcurve .mod file using BinaryModel.from_file() or from an instance of lcurve.Model using BinaryModel.from_model().

Parameters can be updated by supplying a python dictionary of parameter key: value pairs to BinaryModel.update().

bright_spot_grid#
compute_light_curve(time, t_exp, n_div=None, flux=None, flux_err=None, weight=None, scale_factor=None)#

grid options are: “star1_fine”, “star1_coarse”, “star2_fine”, “star2_coarse”, “disc”, “disc_edge”, “bright_spot”

Computes a model light curve for an array of times and exposure times for the current parameters defined in BinaryModel.Model.

Parameters:

  • time: Array of times

  • t_exp: Array of exposure times (same units as time)

  • n_div: (Optional) number of exposure subdivisions to use to model

    smearing from finite exposure times.

  • flux: (Optional) flux of data to enable automatic scaling of the model

    as well as for calculations of chi2 and log_prob.

  • flux_err: (Optional) flux uncertainty of data to enable automatic

    scaling of the model as well as for calculations of chi2 and log_prob.

  • weight: (Optional) weights for autoscaling, chi2, and log_prob

  • scale_factor: (Optional) Scale factor to multiply light curve model

    by. Prevents autoscaling

Returns:

LightCurve

project_2d(q, iangle, phase)#

Projects the grid onto a 2D plane as seen at the model inclination at the supplied phase with the binary centre of mass as the origin.

Arguments * q - Binary mass ratio M2/M1. * iangle - Orbital inclination at which to project the grid. * phase - Orbital phase at which to project the grid

Returns (x, y) - Arrays of projected grid point positions
